# Lilycrest AI Workflow Knowledge Pack

## How to use these files

Read `00_SYSTEM_CONTEXT.md` first. It defines the tenant lifecycle,
system invariants, and the rule for unresolved business logic.

Then load the module-specific files relevant to the code being changed:

1.  `01_INQUIRY_APPLICATION_RATES.md`
2.  `02_RESERVATION_INVENTORY_MOVEIN.md`
3.  `03_CONTRACT_AND_RENT_BILLING.md`
4.  `04_ELECTRICITY_BILLING.md`
5.  `05_PAYMENTS_DELINQUENCY_DISPUTES.md`
6.  `06_TENANT_LIFECYCLE.md`
7.  `07_STATUSES_VALIDATION_RULES.md`
8.  `08_WORKED_EXAMPLES_AND_BUILD_ORDER.md`

## Important

These files are derived from the Lilycrest Gil Puyat Developer Workflow
Manual, Version 1.0 --- August 2026.

Do not invent missing business rules. The source manual explicitly
requires unresolved rules to remain configurable or require manual
approval.
